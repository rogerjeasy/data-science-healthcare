# Appendix: harmonisation rules (step 1)

Generated by `python scripts/build_dataset.py` from `src/hidden_risk/variables.py`. Do not edit by hand. The full variable list is in [`codebook.md`](codebook.md).

## Rules applied to every cycle

1. **Stored zeros.** SAS transport stores 0 as about 5.4e-79; every value below 1e-30 in absolute size is set to 0 on import.
2. **Merge.** Within a cycle, all modules are left-joined on `SEQN` to the demographics file, so every participant is kept. The prescription file has one row per drug: its person-level answers (`RXDUSE`, `RXDCOUNT`) are merged, and the drugs go to a separate long table.
3. **Cohort.** Adults (18+) who answered all nine PHQ-9 items. A refused or don't-know item counts as not answered.
4. **Refused / don't know.** The codes depend on the variable (table below), because 7 and 9 are real answers for some variables, such as hours of sleep.
5. **Age coverage.** A variable is kept only for the ages asked in every cycle and set to missing outside them, so missingness does not reveal the survey year in the temporal validation (H4).
6. **Not collected.** A variable that a cycle did not collect is missing for that whole cycle.
7. **Yes / no questions** are recoded from NHANES 1 = yes, 2 = no to 1 = yes, 0 = no.

## Refused / don't know codes set to missing

| Codes | Variables |
|---|---|
| none | `age`, `sex`, `ethnicity`, `income_poverty_ratio`, `weight_interview`, `weight_mec`, `strata`, `psu`, `bmi`, `rx_count` |
| 7, 9 | `education`, `phq_1`, `phq_2`, `phq_3`, `phq_4`, `phq_5`, `phq_6`, `phq_7`, `phq_8`, `phq_9`, `phq_difficulty`, `self_rated_health`, `hospital_stay`, `mental_health_visit`, `asthma`, `arthritis`, `heart_failure`, `coronary_heart_disease`, `angina`, `heart_attack`, `stroke`, `emphysema`, `chronic_bronchitis`, `copd`, `liver_condition`, `thyroid_problem`, `cancer`, `diabetes`, `hypertension`, `high_cholesterol`, `sleep_trouble`, `smoked_100_cigarettes`, `smoking_now`, `ever_marijuana`, `ever_hard_drugs`, `ever_injected_drugs`, `work_status`, `insured`, `rx_any` |
| 77, 99 | `marital_status`, `healthcare_visits`, `sleep_hours` |

## Variables that differ between cycles

| Variable | NHANES source | Ages kept | Rule |
|---|---|---|---|
| `age` | `RIDAGEYR` | all | Top-coded at 80 in all cycles (2005-06 used 85). |
| `education` | `DMDEDUC2` | all | DMDEDUC2 is asked from age 20; for ages 18-19 it is derived from DMDEDUC3. |
| `marital_status` | `DMDMARTL` | 20+ | Asked from age 20 (2005-06 from 14); set missing under 20 in every cycle. |
| `healthcare_visits` | `HUQ050` (2005-2012), `HUQ051` (2013-2018) | all | HUQ051 (2013+) categories collapsed to HUQ050's. HUQ050 includes emergency-room and home visits, HUQ051 excludes them. |
| `copd` | `MCQ160O` (2013-2018) | all | Only asked from 2013; use emphysema / chronic bronchitis for all cycles. |
| `diabetes` | `DIQ010` | all | Borderline (code 3) counted as no. |
| `high_cholesterol` | `BPQ080` | 20+ | Until 2010 only asked if cholesterol was ever checked; never checked (BPQ060 = no) is set to no, as from 2011 everyone is asked. Asked from age 20 until 2012, from 18 afterwards; set missing under 20. |
| `sleep_hours` | `SLD010H` (2005-2014), `SLD012` (2015-2018) | all | New sleep module from 2015: SLD012 (half hours, 2-14.5) replaces SLD010H (whole hours, 12 = 12 or more). Clipped to 2-12 in all cycles. |
| `smoked_100_cigarettes` | `SMQ020` | 20+ | Asked from age 20 until 2012, from 18 afterwards; set missing under 20. |
| `smoking_now` | `SMQ040` | 20+ | Only asked if smoked_100_cigarettes = yes, so it follows the same age rule. |
| `ever_marijuana` | `DUQ200` | 20-59 | Asked to ages 20-59 (2005-08) or 18-59 (2009+); set missing under 20. |
| `ever_hard_drugs` | `DUQ240` | 20-59 | Asked to ages 20-59 (2005-06), 20-69 (2007-08) or 18-69 (2009+); kept for 20-59. |
| `ever_injected_drugs` | `DUQ370` | 20-59 | Asked to ages 20-59 (2005-06), 20-69 (2007-08) or 18-69 (2009+); kept for 20-59. |
| `rx_count` | `RXDCOUNT` | all | Set to 0 when rx_any = no. |
